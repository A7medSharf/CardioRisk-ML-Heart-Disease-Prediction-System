# ❤️ CardioRisk ML – Heart Disease Prediction System

## 📌 Project Overview
CardioRisk ML is a supervised machine learning project designed to predict the likelihood of heart disease using structured clinical data.

The goal is to develop a reliable classification model that supports early risk detection through data-driven analysis and statistical modeling.

---

## 📊 Dataset Information
- Domain: Healthcare
- Target Variable: `target`
  - 0 → No Heart Disease
  - 1 → Presence of Heart Disease
- Features include:
  - Age
  - Sex
  - Chest Pain Type
  - Resting Blood Pressure
  - Cholesterol
  - Maximum Heart Rate (thalach)
  - And other clinical indicators
